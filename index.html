Comprender la creacion de un repositorio y sus funcionalidades

Los Integrantes: Dominguez, Elkin, Leon

• ¿Qué es? Un sistema que guarda el historial de cambios de un proyecto. • ¿Por qué es importante? Evita perder trabajo, permite recuperar versiones anteriores, ordena el trabajo en equipo y deja registro de quién hizo cada cambio. • Ejemplo de utilidad: si una modificación daña el programa, se vuelve a la versión que funcionaba. O si dos personas editan el mismo proyecto, no se pisan el trabajo ni terminan con archivos como “proyecto_final_v2_definitivo”.

• Git: sistema de control de versiones que se instala y funciona en la computadora. Sirve para registrar cambios, crear versiones y volver atrás. • GitHub: plataforma en internet donde se alojan repositorios de Git para guardarlos en la nube, compartirlos y colaborar.
